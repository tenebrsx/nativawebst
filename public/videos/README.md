# Video Assets

Drop any video files (`.mp4`, `.webm`, `.mov`) into this folder (`public/videos/`).

- **Next.js URL:** Files placed in `public/videos/example.mp4` are automatically accessible on the web at `/videos/example.mp4`.
- **AI Analysis:** You can mention the filename in chat (e.g., "Look at `hero-animation.mp4` in `public/videos/`") and I will inspect and analyze the video frame-by-frame.
